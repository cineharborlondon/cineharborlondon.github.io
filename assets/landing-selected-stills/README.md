# Selected landing-page stills

The active homepage selection contains 120 compressed landscape stills from the approved source set. Each image is held for 500 ms for a nominal 60-second cycle, with a new randomized order on every visit.

The active paths are listed in `landing-frames.js`. Use one consistent opaque `sourceGroup` per source so related images remain separated. The filenames and groups are neutral; original recordings and private selection notes stay outside the public website.

The previous images in `assets/landing-library-stills/` are retained for rollback and are no longer referenced by the active manifest. Check all paths, desktop and mobile layout, and entry to Work before publishing a new selection.
